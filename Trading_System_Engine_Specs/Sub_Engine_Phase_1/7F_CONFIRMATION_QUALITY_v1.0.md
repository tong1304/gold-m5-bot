# 7F — CONFIRMATION QUALITY

## 1. INPUT
7A–7E confirmation evidence.

## 2. PROCESSING
Aggregate trigger quality, follow-through, failure state and execution-condition evidence into confirmation quality.

## 3. OUTPUT
Confirmation-quality score, components, confidence, reasons.

## 4. GATE
BLOCK when mandatory confirmation evidence fails.

## 5. SCORE
0–100 evidence score; cannot override gates or make the final decision.

## 6. TRACEABILITY
Record component versions, trigger/setup IDs, timestamp, score, gate.

**DECISION BOUNDARY:** confirmation quality only.
