# 5E Available Space

## 1. INPUT
- Current price plus validated structural, liquidity and value objectives.

## 2. PROCESSING
- Measure unobstructed price distance to relevant opposing levels/objectives.

## 3. OUTPUT
- Available-space measurements, nearest opposing obstacles and confidence.

## 4. GATE
- FAIL when opposing references cannot be established reliably.
- This is a location constraint, not an entry decision.

## 5. SCORE
- 0-100 space-quality score from distance reliability and obstacle clarity.

## 6. TRACEABILITY
- Record objective IDs, distance method, timestamp, output and reason codes.
