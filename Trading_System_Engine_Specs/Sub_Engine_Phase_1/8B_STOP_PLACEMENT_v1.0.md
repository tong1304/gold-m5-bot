# 8B — STOP PLACEMENT

## 1. INPUT
8A invalidation model, price/structure references, risk parameters.

## 2. PROCESSING
Derive a stop level consistent with the risk invalidation model and configured constraints.

## 3. OUTPUT
Stop level, distance, assumptions, confidence, reasons.

## 4. GATE
BLOCK when stop cannot satisfy required invalidation/risk constraints.

## 5. SCORE
Stop-quality score 0–100; evidence only.

## 6. TRACEABILITY
Record inputs, formula/version, stop calculation, timestamp, gate, score.

**DECISION BOUNDARY:** stop calculation only.
