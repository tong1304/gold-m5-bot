# 2F — REGIME TRANSITION

## 1. INPUT
E1 state transitions and E2 regime history.

## 2. PROCESSING
Detect behavioral regime changes using persistence; distinguish physical-state transition (1G) from regime transition.

## 3. OUTPUT
Regime transition state, from/to regime, evidence, confidence, reasons.

## 4. GATE
BLOCK when transition evidence is incomplete or contradictory.

## 5. SCORE
Transition quality 0–100; evidence only.

## 6. TRACEABILITY
Record prior/current regimes, upstream versions, transition timestamp, score, gate.

**DECISION BOUNDARY:** regime transition only.
