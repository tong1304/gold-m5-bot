# 6D — SETUP INVALIDATION

## 1. INPUT
Setup definition, 6B–6C state, upstream structure/liquidity/location evidence.

## 2. PROCESSING
Determine whether the setup thesis/state has been invalidated under its own definition.

## 3. OUTPUT
Valid/invalid/hold state, invalidation reason, confidence, reasons.

## 4. GATE
FAIL setup when a defined setup-invalidation condition occurs.

## 5. SCORE
Invalidation evidence quality 0–100; cannot authorize a trade.

## 6. TRACEABILITY
Record setup ID/version, invalidation rule, triggering candle/event, timestamp, gate.

**DECISION BOUNDARY:** setup validity only; risk invalidation is owned by E8.
