# 3F Internal vs External Structure

## 1. INPUT
- Confirmed swing hierarchy and structural levels from 3A-3E.

## 2. PROCESSING
- Separate local/internal structure from higher-significance/external structure using the approved hierarchy rules.

## 3. OUTPUT
- Internal/external labels, linked levels, hierarchy evidence and confidence.

## 4. GATE
- FAIL when hierarchy cannot be established reliably.

## 5. SCORE
- 0-100 hierarchy-quality score based on level significance and consistency.

## 6. TRACEABILITY
- Record hierarchy ruleset, linked swing IDs, timestamp, labels and reason codes.
