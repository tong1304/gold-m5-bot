# 3F — INTERNAL VS EXTERNAL STRUCTURE

## 1. INPUT
Confirmed swing hierarchy from 3A–3B and structural events.

## 2. PROCESSING
Separate local/internal swings from higher-order/external structure using explicit hierarchy rules.

## 3. OUTPUT
Structure hierarchy labels, references, confidence, reasons.

## 4. GATE
BLOCK when hierarchy cannot be resolved reliably.

## 5. SCORE
Hierarchy quality 0–100; evidence only.

## 6. TRACEABILITY
Record swing hierarchy, lookback/version, timestamp, score, gate.

**DECISION BOUNDARY:** hierarchy classification only.
