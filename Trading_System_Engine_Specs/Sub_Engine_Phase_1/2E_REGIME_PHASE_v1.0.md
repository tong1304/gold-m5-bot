# 2E — REGIME PHASE

## 1. INPUT
E2 regime classifications and transition evidence.

## 2. PROCESSING
Classify phase within the current behavioral regime (establishment, continuation, exhaustion/other defined phase states).

## 3. OUTPUT
Regime phase, phase evidence, confidence, reasons.

## 4. GATE
BLOCK when regime identity is unstable or insufficiently evidenced.

## 5. SCORE
Phase quality 0–100; evidence only.

## 6. TRACEABILITY
Record regime version, phase rules, timestamp, score, gate, reasons.

**DECISION BOUNDARY:** phase classification only.
