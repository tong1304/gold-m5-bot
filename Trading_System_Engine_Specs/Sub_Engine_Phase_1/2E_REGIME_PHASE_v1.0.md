# 2E Regime Phase

## 1. INPUT
- Current and prior regime classifications plus transition and volatility evidence.

## 2. PROCESSING
- Identify phase such as EARLY, DEVELOPING, MATURE or LATE where evidence supports it.

## 3. OUTPUT
- Regime phase, supporting evidence, maturity quality and confidence.

## 4. GATE
- FAIL when phase history is insufficient or contradictory.
- Phase is context only.

## 5. SCORE
- 0-100 phase-quality score based on persistence and consistency.

## 6. TRACEABILITY
- Record regime history window, phase ruleset, timestamp, output and reason codes.
