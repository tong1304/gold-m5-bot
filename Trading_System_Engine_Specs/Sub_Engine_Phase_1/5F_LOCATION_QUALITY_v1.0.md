# 5F — LOCATION QUALITY

## 1. INPUT
5A–5E location evidence.

## 2. PROCESSING
Assess consistency and clarity of value, structure, liquidity, extension and space evidence.

## 3. OUTPUT
Location-quality score, component evidence, confidence, reasons.

## 4. GATE
BLOCK when essential location references conflict beyond defined tolerance.

## 5. SCORE
0–100 evidence score; cannot authorize entry.

## 6. TRACEABILITY
Record component versions, references, score, gate, timestamp.

**DECISION BOUNDARY:** location quality only.
