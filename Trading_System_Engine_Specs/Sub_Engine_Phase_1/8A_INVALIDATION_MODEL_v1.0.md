# 8A Invalidation Model

## 1. INPUT
- Valid setup/trigger state, structural levels, liquidity references and invalidation evidence.

## 2. PROCESSING
- Define the objective condition under which the setup thesis is considered invalid for risk purposes.

## 3. OUTPUT
- Invalidation level/model, rationale, reference IDs and confidence.

## 4. GATE
- FAIL when no defensible invalidation model can be established.
- No entry decision.

## 5. SCORE
- 0-100 invalidation-model quality based on structural clarity and robustness.

## 6. TRACEABILITY
- Record source levels, model version, timestamp, output and reason codes.
