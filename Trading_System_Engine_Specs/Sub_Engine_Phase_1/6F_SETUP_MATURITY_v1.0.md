# 6F Setup Maturity

## 1. INPUT
- Setup state history, age, formation events and invalidation status.

## 2. PROCESSING
- Classify maturity as EARLY, DEVELOPING, MATURE, OVEREXTENDED or INVALID only under defined evidence rules.

## 3. OUTPUT
- Maturity state, age/event evidence, quality and confidence.

## 4. GATE
- FAIL when setup history is incomplete or state is invalid.

## 5. SCORE
- 0-100 maturity-quality score reflecting evidence completeness, not desirability.

## 6. TRACEABILITY
- Record setup state history, event IDs, timestamp, maturity rule/version and reason codes.
