# 3E Structure Strength

## 1. INPUT
- Structure sequence, swing prominence, BOS/failure history and volatility context.

## 2. PROCESSING
- Quantify how coherent and persistent the current structure is.

## 3. OUTPUT
- Structure-strength state, component evidence, quality and confidence.

## 4. GATE
- FAIL only when required structure evidence is unavailable.

## 5. SCORE
- 0-100 strength score from sequence clarity, persistence and confirmation quality.

## 6. TRACEABILITY
- Store component scores, source event IDs, timestamp, final score and reason codes.
