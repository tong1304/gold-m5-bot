# 3D — STRUCTURAL FAILURE

## 1. INPUT
3B structure and 3C break events plus closed-candle evidence.

## 2. PROCESSING
Determine whether a previously valid structural continuation failed; do not classify liquidity interaction here.

## 3. OUTPUT
Failure state, affected structure, evidence, confidence, reasons.

## 4. GATE
BLOCK when the underlying structure is not confirmed.

## 5. SCORE
Failure quality 0–100; evidence only.

## 6. TRACEABILITY
Record structure IDs, event candles, upstream versions, score, gate, timestamp.

**DECISION BOUNDARY:** structural failure only.
