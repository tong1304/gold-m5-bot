# 9C Setup Gate

## 1. INPUT
- Setup context, archetype, formation, invalidation, quality and maturity outputs.

## 2. PROCESSING
- Verify that a setup is defined, valid, sufficiently formed and compatible with the context contract.

## 3. OUTPUT
- Setup gate status, setup ID, blocking conditions and confidence.

## 4. GATE
- FAIL when setup requirements are missing, invalidated or contradictory.

## 5. SCORE
- 0-100 setup-readiness score; it cannot turn an invalid setup into PASS.

## 6. TRACEABILITY
- Record setup/component IDs, versions, timestamp, gate result and reason codes.
