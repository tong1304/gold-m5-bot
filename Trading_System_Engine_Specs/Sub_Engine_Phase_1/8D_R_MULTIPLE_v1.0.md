# 8D R-Multiple

## 1. INPUT
- Entry reference, stop distance and validated target/objective distance.

## 2. PROCESSING
- Calculate risk-unit distance and candidate reward-to-risk multiple using the approved arithmetic convention.

## 3. OUTPUT
- Risk distance, reward distance, R-multiple and calculation status.

## 4. GATE
- FAIL when entry/stop/target geometry is invalid or risk distance is non-positive.

## 5. SCORE
- No independent quality score required; may expose calculation confidence 0-100 based on input validity.

## 6. TRACEABILITY
- Record all price inputs, calculation version, timestamp, result and reason codes.
