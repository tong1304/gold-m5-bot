# 5D Extension

## 1. INPUT
- Current price, value reference, structural range and permitted volatility normalization.

## 2. PROCESSING
- Measure how extended price is from relevant equilibrium/structure references without assuming reversal.

## 3. OUTPUT
- Extension state, normalized distance and confidence.

## 4. GATE
- FAIL when the reference range or normalization data is invalid.

## 5. SCORE
- 0-100 measurement-quality score from reference stability and distance reliability.

## 6. TRACEABILITY
- Record reference IDs, normalization method, timestamp, state and reason codes.
