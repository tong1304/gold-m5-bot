# 5D — EXTENSION

## 1. INPUT
Current price, validated structure/value references, permitted range measures.

## 2. PROCESSING
Measure price extension from defined structural/value anchors without predicting reversal.

## 3. OUTPUT
Extension state, normalized distance, confidence, reasons.

## 4. GATE
BLOCK when anchors or normalization baseline is invalid.

## 5. SCORE
Extension quality 0–100; evidence only.

## 6. TRACEABILITY
Record anchors, measurements, version, timestamp, score, gate.

**DECISION BOUNDARY:** extension measurement only.
