# 2A — TREND REGIME

## 1. INPUT
E1 market-state outputs, permitted price/volatility evidence.

## 2. PROCESSING
Interpret persistent directional behavior as a behavioral regime using E1 evidence; do not recalculate E1 states unnecessarily.

## 3. OUTPUT
Trend-regime classification, supporting evidence, confidence, reason codes.

## 4. GATE
BLOCK when required E1 state evidence is invalid/unavailable.

## 5. SCORE
Regime quality 0–100; evidence only.

## 6. TRACEABILITY
Record E1 versions, timestamp, regime rules, state, score, gate, reason codes.

**DECISION BOUNDARY:** behavioral regime only.
