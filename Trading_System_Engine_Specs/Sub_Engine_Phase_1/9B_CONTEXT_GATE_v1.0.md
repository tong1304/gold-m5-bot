# 9B Context Gate

## 1. INPUT
- Market state, regime, structure, liquidity and location outputs.

## 2. PROCESSING
- Verify that required context is coherent and satisfies the parent decision contract.

## 3. OUTPUT
- Context gate status, conflicts, supporting evidence and confidence.

## 4. GATE
- FAIL when mandatory context is invalid or contains unresolved blocking contradictions.

## 5. SCORE
- 0-100 context-readiness score for diagnostics only.

## 6. TRACEABILITY
- Record upstream versions, state snapshot, timestamp, gate result and reason codes.
