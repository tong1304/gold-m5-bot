# 9B — CONTEXT GATE

## 1. INPUT
Validated E1–E5 context outputs.

## 2. PROCESSING
Verify required market/regime/structure/liquidity/location context is coherent for final decision evaluation.

## 3. OUTPUT
PASS/FAIL context gate, missing/conflicting evidence, summary.

## 4. GATE
FAIL when mandatory context is missing, invalid, or materially contradictory.

## 5. SCORE
Context coherence 0–100; informational only.

## 6. TRACEABILITY
Record upstream versions, conflicts, timestamp, gate, reasons.

**DECISION BOUNDARY:** final context validation only.
