# 7C — FOLLOW-THROUGH

## 1. INPUT
Confirmed trigger, subsequent closed candles permitted by the trigger contract.

## 2. PROCESSING
Measure persistence after trigger without using future information beyond the current evaluation point.

## 3. OUTPUT
Follow-through state, persistence evidence, confidence, reasons.

## 4. GATE
BLOCK when required follow-through window is not available for the requested evaluation.

## 5. SCORE
Follow-through quality 0–100; evidence only.

## 6. TRACEABILITY
Record trigger candle, evaluation window, measurements, timestamp, score, gate.

**DECISION BOUNDARY:** confirmation evidence only.
