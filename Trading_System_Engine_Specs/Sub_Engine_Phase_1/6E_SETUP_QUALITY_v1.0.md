# 6E — SETUP QUALITY

## 1. INPUT
6A–6D evidence.

## 2. PROCESSING
Evaluate clarity, completeness, alignment and integrity of setup evidence.

## 3. OUTPUT
Setup-quality score/components, confidence, reasons.

## 4. GATE
BLOCK when mandatory setup evidence is invalid.

## 5. SCORE
0–100 evidence score; cannot override hard gates.

## 6. TRACEABILITY
Record component evidence, weights/version, timestamp, score, gate.

**DECISION BOUNDARY:** setup quality only.
