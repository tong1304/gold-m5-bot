# 6E Setup Quality

## 1. INPUT
- Setup context, archetype, formation state, invalidation status and evidence quality.

## 2. PROCESSING
- Evaluate setup completeness and coherence without deciding entry direction.

## 3. OUTPUT
- Setup-quality state, component evidence, confidence and reason codes.

## 4. GATE
- FAIL when mandatory setup components are invalid or the setup is explicitly invalidated.

## 5. SCORE
- 0-100 setup-quality score from defined component evidence; hard invalidation overrides score.

## 6. TRACEABILITY
- Record setup ID, component versions, score components, timestamp and reason codes.
