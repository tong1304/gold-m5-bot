# 5A — EQUILIBRIUM / VALUE

## 1. INPUT
Validated price data plus permitted value references.

## 2. PROCESSING
Determine price relationship to the selected equilibrium/value reference; reference calculation must be versioned.

## 3. OUTPUT
Value state, distance/relationship, confidence, reasons.

## 4. GATE
BLOCK when the value reference is unavailable, stale, or invalid.

## 5. SCORE
Value-location quality 0–100; evidence only.

## 6. TRACEABILITY
Record reference type/version, price, distance, timestamp, score, gate.

**DECISION BOUNDARY:** value relationship only.
