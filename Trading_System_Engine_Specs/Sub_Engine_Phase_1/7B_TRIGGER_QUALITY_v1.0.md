# 7B Trigger Quality

## 1. INPUT
- Trigger event from 7A, candle anatomy, volatility context and setup evidence.

## 2. PROCESSING
- Evaluate trigger clarity, strength and consistency with the parent setup.

## 3. OUTPUT
- Trigger-quality state, component evidence and confidence.

## 4. GATE
- FAIL when trigger evidence is invalid or materially conflicts with setup requirements.

## 5. SCORE
- 0-100 trigger-quality score; it cannot override setup or risk hard gates.

## 6. TRACEABILITY
- Record trigger ID, candle metrics, ruleset/version, score and reason codes.
