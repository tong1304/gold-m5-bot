# 7B — TRIGGER QUALITY

## 1. INPUT
7A trigger and permitted candle/volatility evidence.

## 2. PROCESSING
Assess trigger clarity, displacement, close quality and consistency with the defined trigger.

## 3. OUTPUT
Trigger-quality score/components, confidence, reasons.

## 4. GATE
BLOCK when trigger evidence is malformed or invalid.

## 5. SCORE
0–100 evidence score; hard gates prevail.

## 6. TRACEABILITY
Record trigger ID, component measurements, version, timestamp, score, gate.

**DECISION BOUNDARY:** trigger quality only.
