# 8C — TARGET / LIQUIDITY OBJECTIVE

## 1. INPUT
Validated opposing structure/liquidity/location references, current price, risk model.

## 2. PROCESSING
Identify objective target references; do not decide whether a trade should be taken.

## 3. OUTPUT
Target/objective level(s), reference IDs, distance, confidence, reasons.

## 4. GATE
BLOCK when a defensible objective is unavailable.

## 5. SCORE
Objective quality 0–100; evidence only.

## 6. TRACEABILITY
Record target reference, source engine/version, calculation, timestamp, score, gate.

**DECISION BOUNDARY:** objective modeling only.
