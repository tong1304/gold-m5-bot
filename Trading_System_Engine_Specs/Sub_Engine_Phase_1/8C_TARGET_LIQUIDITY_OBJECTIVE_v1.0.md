# 8C Target / Liquidity Objective

## 1. INPUT
- Validated liquidity zones, structural objectives, value references and current price.

## 2. PROCESSING
- Identify candidate objective levels consistent with the setup context; rank by relevance without guaranteeing attainment.

## 3. OUTPUT
- Objective levels, source IDs, distance metrics and confidence.

## 4. GATE
- FAIL when no defensible objective exists under the parent risk contract.

## 5. SCORE
- 0-100 objective-quality score based on level quality and distance clarity.

## 6. TRACEABILITY
- Record objective IDs, source engine versions, timestamp, score and reason codes.
