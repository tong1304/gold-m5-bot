# 3B — STRUCTURE CLASSIFICATION

## 1. INPUT
Confirmed swings from 3A and permitted E1–E2 context.

## 2. PROCESSING
Classify HH/HL/LH/LL and structural sequence; do not decide trade direction.

## 3. OUTPUT
Structural classification, sequence evidence, confidence, reasons.

## 4. GATE
BLOCK when swing sequence is incomplete or invalid.

## 5. SCORE
Structure quality 0–100; evidence only.

## 6. TRACEABILITY
Record swing IDs, sequence, rules/version, timestamp, score, gate.

**DECISION BOUNDARY:** structure classification only.
