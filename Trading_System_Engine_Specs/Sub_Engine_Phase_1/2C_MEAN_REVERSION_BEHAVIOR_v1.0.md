# 2C — MEAN-REVERSION BEHAVIOR

## 1. INPUT
E1 states, E2 context, permitted value/price evidence.

## 2. PROCESSING
Assess evidence that price behavior tends to return toward an established reference; do not create an entry setup.

## 3. OUTPUT
Mean-reversion behavior state, evidence, confidence, reasons.

## 4. GATE
BLOCK when reference/value evidence is unavailable or invalid.

## 5. SCORE
Behavior quality 0–100; evidence only.

## 6. TRACEABILITY
Record reference, inputs, timestamp, state, score, gate, reason codes.

**DECISION BOUNDARY:** behavioral characterization only.
