# 4F — LIQUIDITY STRENGTH / QUALITY

## 1. INPUT
4A–4E liquidity evidence.

## 2. PROCESSING
Aggregate observable zone quality, freshness, interaction clarity and persistence into evidence quality.

## 3. OUTPUT
Liquidity-quality score, supporting components, confidence, reasons.

## 4. GATE
BLOCK when essential liquidity evidence is invalid.

## 5. SCORE
0–100 evidence score; hard gates remain authoritative.

## 6. TRACEABILITY
Record component IDs, weights/version, timestamp, score, gate.

**DECISION BOUNDARY:** quality assessment only.
