# 4F Liquidity Strength / Quality

## 1. INPUT
- Liquidity zones, sweep/reaction/acceptance events and structural significance.

## 2. PROCESSING
- Aggregate evidence to classify liquidity relevance and reliability without deciding trade direction.

## 3. OUTPUT
- Liquidity-quality state, strength score components and confidence.

## 4. GATE
- FAIL when source zone/event evidence is insufficient.

## 5. SCORE
- 0-100 quality score from zone clarity, repeated interaction and event confirmation.

## 6. TRACEABILITY
- Record all contributing zone/event IDs, weights/version, timestamp and reason codes.
