# 6B — SETUP ARCHETYPE

## 1. INPUT
Validated setup context and versioned archetype definitions.

## 2. PROCESSING
Match observable evidence to a defined setup archetype; no independent trade authorization.

## 3. OUTPUT
Archetype ID, matching evidence, state, confidence, reasons.

## 4. GATE
BLOCK/NO_SETUP when no valid archetype matches or mandatory evidence is absent.

## 5. SCORE
Archetype quality 0–100; evidence only.

## 6. TRACEABILITY
Record definition/version, evidence IDs, timestamp, score, gate.

**DECISION BOUNDARY:** setup identification only.
