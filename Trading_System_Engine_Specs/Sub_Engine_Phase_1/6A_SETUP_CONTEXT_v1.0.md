# 6A Setup Context

## 1. INPUT
- Market state, regime, structure, liquidity and location outputs from Engines 1-5.

## 2. PROCESSING
- Describe the environment in which a setup could be evaluated; do not invent an entry pattern.

## 3. OUTPUT
- Setup-context object, compatible contexts, conflicts and confidence.

## 4. GATE
- FAIL when required upstream context is invalid or missing.

## 5. SCORE
- 0-100 context-quality score based on completeness and coherence.

## 6. TRACEABILITY
- Record all upstream engine/sub-engine versions, timestamp, context state and reason codes.
