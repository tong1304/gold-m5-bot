# 6A — SETUP CONTEXT

## 1. INPUT
E1–E5 outputs and permitted setup-context definitions.

## 2. PROCESSING
Assemble the context required to evaluate setup archetypes without selecting an entry.

## 3. OUTPUT
Setup context state, relevant evidence IDs, confidence, reasons.

## 4. GATE
BLOCK when mandatory context evidence is missing or invalid.

## 5. SCORE
Context quality 0–100; evidence only.

## 6. TRACEABILITY
Record upstream versions, context rules/version, timestamp, score, gate.

**DECISION BOUNDARY:** context assembly only.
